# Full Stack Open

## Phonebook

Run the backend from `part-3`:

```bash
npm start
```

The application is available locally at [http://localhost:3001](http://localhost:3001).

For development with automatic restart:

```bash
npm run dev
```

### Deployment

Deploy the `part-3` directory to a Node hosting provider such as Render. Use:

- Build command: `npm install`
- Start command: `npm start`

After deployment, replace the local URL above with the public application URL.
